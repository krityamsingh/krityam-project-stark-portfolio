# PROJECT STARK — Krityam Singh

An original cinematic portfolio showcasing real projects, source links, and creative work.

Built with React and Vite. Deploys on Vercel.

## Projects
- GenesisX
- AI Clipping
- SEO Automation
- Kenerate AI Ad
- FrontierAtlas

## Local development
```bash
npm install
npm run dev
```

Project videos are displayed when their media files are available under `public/media/`.
